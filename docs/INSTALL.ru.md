# Установка Divinity Original Sin 2 Mobile — по шагам

English version: [INSTALL.md](INSTALL.md).

Divinity Original Sin 2 Mobile запускает **вашу собственную копию** Divinity: Original Sin 2 – Definitive Edition для
Nintendo Switch на Android-телефоне. В проекте нет файлов игры, и он никогда не раздаёт файлы игры или ключи консоли:
вы снимаете их со своей Switch. Программа установки (setup) на ПК превращает ваш дамп в папку игры (~13 ГБ), вы копируете
её на телефон и ставите приложение.

Всё вместе занимает 30–60 минут, в основном копирование и ожидание setup.

## Что нужно

**С вашей Switch** (см. шаг 1):

| Что | Подробности |
|---|---|
| Базовая игра Divinity: Original Sin 2 – Definitive Edition | title id `010027400CDC6000`, с картриджа или из eShop |
| Обновление **v786432** | title id `010027400CDC6800` (последнее). Работает только это обновление (порт сделан под его код). Программы дампа обычно пишут версию в имя файла, например `...[010027400CDC6800][v786432].nsp` |
| `prod.keys` | ключи **вашей** консоли |

Языковые пакеты и DLC не нужны: языки игры и контент *Gift Bag* уже есть в базовой игре.

Игра и обновление могут быть **NSP, NSZ, XCI или XCZ** в любом сочетании. Подходят и разбитые дампы с карты FAT32
(папка с частями `00`, `01`, … или `name.xc0`, `name.xc1`, …). Имена файлов не важны: setup узнаёт файлы по содержимому.

Сенсорный интерфейс (меню, экранные кнопки HUD, колонка кнопок у правого края, ряды кнопок в панелях) собирается только
из этих файлов Switch; рисунки кнопок — собственные, проекта. Другая версия игры не нужна.

**ПК** с Windows 10/11 (64-бит), Linux или macOS:

- около **20 ГБ свободного места** на время подготовки (до ~32 ГБ с NSZ / XCZ);
- интернет при первом запуске: setup скачивает несколько вспомогательных программ (пакеты Python ~60 МБ, Microsoft .NET
  ~300 МБ, инструменты SPIR-V из Android NDK Google ~7 МБ и, на Windows без Python, сам Python ~15 МБ). Перед каждой загрузкой он спрашивает и кладёт всё только в свою
  папку. Дальше работает без интернета.

**Телефон:**

- Android 12 или новее, 64-бит (Android 10 и 11 — отдельный APK `-android10`, шаг 6);
- **рекомендуется Snapdragon с GPU Adreno** (проверено на Snapdragon 8 Gen 3; телефоны с Mali / PowerVR / Xclipse
  работают на своём драйвере с обходами в движке и не проверялись);
- 8 ГБ ОЗУ или больше;
- около **13 ГБ свободного места** во внутренней памяти (около **15 ГБ** с папкой `astc`, которая нужна телефонам без
  BC, см. шаг 5);
- USB-кабель (или другой способ скопировать папку на телефон).

## Шаг 1. Снимите файлы игры и ключи со Switch

**Дамп своими силами.** Нужна Switch, на которой запускается homebrew (как этого добиться, здесь не описано).
1. Установите на Switch игру и последнее обновление (v786432).
2. Снимите их через [nxdumptool](https://github.com/DarkMatterCore/nxdumptool): установленная или eShop-копия → *NSP*;
   картридж → *XCI* (установленное обновление снимается отдельно как NSP). Для NSP включите
   **«remove console specific data»** — иначе обновление на ПК не прочитать.
3. Снимите ключи консоли через [Lockpick_RCM](https://github.com/shchmue/Lockpick_RCM). Файл `prod.keys` появится на
   SD-карте в `switch/`.
4. Скопируйте файлы на ПК.

Не скачивайте файлы игры и ключи из интернета и не раздавайте свои.

## Шаг 2. Скачайте setup Divinity Original Sin 2 Mobile

Скачайте этот репозиторий архивом ZIP (зелёная кнопка **Code** → **Download ZIP**) или клонируйте его и распакуйте на диск
с достаточным местом, в короткий путь вроде `D:\DOS2-setup`. В папке будут `setup.bat`, `setup.sh` и папка
`put-game-files-here`.

## Шаг 3. Положите файлы в `put-game-files-here`

```
<папка setup>/
├── setup.bat
├── setup.sh
└── put-game-files-here/
    ├── Divinity Original Sin 2 ... [010027400CDC6000][v0].nsp         (или .nsz / .xci / .xcz — базовая игра)
    ├── Divinity Original Sin 2 ... [010027400CDC6800][v786432].nsp    (обновление)
    └── prod.keys
```

Можно положить туда и папку от программы дампа как есть (setup смотрит на две папки в глубину).

## Шаг 4. Запустите setup

### Windows

1. **Дважды щёлкните `setup.bat`.** Если Windows предупреждает о файле из интернета, выберите **Выполнить** (или
   **Подробнее → Выполнить в любом случае**).
2. Отвечайте **Y** и Enter (просто Enter — тоже «да»): *Скачать собственный Python?* (только если на ПК нет Python
   3.10+), *Установить пакеты Python?*, *Скачать и установить .NET 10 SDK?*, *Download them there now?* (инструменты
   SPIR-V, этап 8). Всё кладётся в `tools\.runtime` внутри папки setup. Ничего не ставится в систему, права
   администратора не нужны.
3. **Ждите.** Setup показывает десять пронумерованных этапов с прогрессом:

   | Этап | Обычно занимает |
   |---|---|
   | 1. Поиск и проверка файлов игры | секунды |
   | 2. Проверка инструментов и места | секунды (в первый раз — загрузка .NET) |
   | 3. Извлечение программы игры | секунды |
   | 4. Патч программы для Android | 1–2 мин |
   | 5. Проверка патча | 1–10 мин |
   | 6. Извлечение данных игры (~11.4 ГБ) | 1–15 мин |
   | 7. Перевод шейдеров (12 329 штук) | 2–20 мин |
   | 8. Слияние шейдеров постобработки (`native-post.xgspack`, `native-nr.xgspack`, `native-nr33b.xgspack`, `native-nr33c.xgspack`) | 3–5 мин (в первый раз — загрузка инструментов SPIR-V, ~7 МБ) |
   | 9. Пакет сенсорного интерфейса | меньше минуты |
   | 10. Текстуры для телефонов без BC (ASTC) | 5–20 мин |

   Свободное место проверяется до начала, при ошибке setup сразу останавливается с понятным сообщением. Если вы закрыли
   окно или ПК выключился, просто запустите setup снова: готовые этапы пропускаются (этап 10 продолжает с места
   остановки). Если у телефона GPU Adreno (Snapdragon), этап 10 можно пропустить: `setup.bat --skip-astc`. Этап 8
   необязательный: если он не получился (например, нет интернета для его инструментов), setup скажет об этом и пойдёт
   дальше; игра тогда рисует проходы постобработки по одному (чуть медленнее), а следующий запуск setup попробует снова.
4. В конце он показывает, где готовая папка, команды adb для копирования и что делать дальше.

Вместо `put-game-files-here` файлы можно просто перетащить на `setup.bat`.

### Linux / macOS

1. Нужен Python 3.10 или новее с модулем `venv` (Debian / Ubuntu: `sudo apt install python3 python3-venv python3-pip`;
   Fedora: `sudo dnf install python3 python3-pip`; Arch: `sudo pacman -S python python-pip`; macOS: `brew install python@3.12`).
2. Откройте терминал в папке setup и выполните `bash setup.sh`. Отвечайте **Y** и ждите (этапы те же, что на Windows).
   Пакеты Python ставятся в `tools/.runtime/venv`, .NET — в `tools/.runtime/dotnet`.

Файлы можно указать и прямо, в любом порядке: `bash setup.sh ~/dumps/dos2-base.nsp ~/dumps/dos2-update.nsp ~/prod.keys`.

### Не знаете, чего не хватает?

Запустите `setup.bat check` (Windows, в терминале в папке setup) или `bash setup.sh check`. Он покажет инструменты,
найденные файлы игры, что уже подготовлено и следующий шаг — ничего не меняя.

## Шаг 5. Скопируйте папку игры на телефон

Готовая папка — **`work/DivinityOriginalSin2Mobile`** внутри папки setup.

- **Передача файлов по USB:** подключите телефон, выберите **Передача файлов**, откройте **внутреннюю память** →
  **Download** и скопируйте туда всю папку **`DivinityOriginalSin2Mobile`**. Должно получиться ровно так:

  ```
  Внутренняя память/Download/DivinityOriginalSin2Mobile/romfs/...
  Внутренняя память/Download/DivinityOriginalSin2Mobile/dm/out/...
  Внутренняя память/Download/DivinityOriginalSin2Mobile/dm/shaders/shaders.xgspack
  Внутренняя память/Download/DivinityOriginalSin2Mobile/dm/shaders/native-post.xgspack
  Внутренняя память/Download/DivinityOriginalSin2Mobile/dm/shaders/native-nr.xgspack     (и native-nr33b / native-nr33c)
  Внутренняя память/Download/DivinityOriginalSin2Mobile/astc/...       (нужна только без BC: Mali, PowerVR, Xclipse)
  Внутренняя память/Download/DivinityOriginalSin2Mobile/drivers/       (свои драйверы Vulkan, необязательно)
  ```

  Папка `astc` (~1.5 ГБ) нужна только телефонам, чей GPU не умеет BC-текстуры (Mali, PowerVR, Xclipse); на телефоне со
  Snapdragon / Adreno её можно не копировать.
- **adb (отладка по USB):** `setup.bat push` / `bash setup.sh push` копирует только недостающее и продолжает после
  обрыва; setup также печатает обычные команды `adb push`.

## Шаг 6. Установите приложение

Установите APK из [последнего релиза](https://github.com/Desm0nt/divinity-original-sin-2-port/releases/latest) или
соберите сами (`build.bat`, см. *Building* в [README-DOS2](../README-DOS2.md)). В первый раз Android попросит разрешить установку
приложений из браузера или файлового менеджера.

- Android 12 или новее: `DOS2-Mobile-v<версия>-arm64.apk`.
- Android 10 или 11: `DOS2-Mobile-v<версия>-arm64-android10.apk` (та же игра, собранная для старого Android; просит
  разрешение на доступ к памяти вместо *Доступа ко всем файлам*; на настоящем Android 10 ещё не проверялась).

## Шаг 7. Первый запуск

1. Запустите **Divinity Original Sin 2 Mobile**.
2. Он попросит **Доступ ко всем файлам** (нужен, чтобы читать `Download/DivinityOriginalSin2Mobile`). Включите и
   вернитесь.
3. Первый запуск и первое посещение каждой сцены дольше последующих (собираются и кэшируются пайплайны Vulkan). Когда
   игра предложит *Steam cross-save*, ответьте **Нет** (сетевой игры нет).
4. Кнопка ⚙ открывает меню паузы и настройки порта: язык, разрешение рендера (по умолчанию — родная высота экрана),
   динамическое разрешение (выкл.), лимит кадров (60), касание как мышь, левый / правый стик, колонка кнопок, драйвер
   Vulkan, счётчик FPS, раскладка управления.

**Игра касанием:** меню отвечают на тапы по пунктам, подсказки кнопок внизу экрана — тоже кнопки. В мире тап — это клик
(идти, говорить, подобрать, атаковать); **долгое нажатие** открывает меню «Действия…» того, что под пальцем;
перетаскивание двигает предметы. Свайп одним пальцем по правой части экрана поворачивает камеру, щипок — зум. Стик
ходьбы появляется под левым большим пальцем в любом месте слева внизу (в ⚙ его можно скрыть — тогда ходьба тапом по
полу). Всё остальное — на экранном паде (крестовина, ABXY, плечевые кнопки, − / +); «Редактировать раскладку» в ⚙
двигает, меняет размер и скрывает его кнопки. В HUD есть и колонка кнопок у правого края (панели персонажа, журнал, карта)
и кнопки параметров, тактической камеры, отмены, конца хода, скрытности и оружия.

Сохранения и настройки хранятся в собственной памяти приложения. Установка нового APK поверх старого их сохраняет; меню
паузы умеет экспортировать и импортировать сохранения.

## Проблемы / FAQ

**«your Divinity Original Sin 2 update is v… ; only v786432 is supported»** — снимите обновление v786432.

**«the Divinity Original Sin 2 base game / the update … is not among the files»** — setup перечисляет все найденные файлы
с title id и версией; проверьте, что в `put-game-files-here` лежат нужные файлы.

**«prod.keys not found» / «your prod.keys has no …» / «does not decrypt with this prod.keys»** — нужны ключи той консоли,
с которой снят дамп, сделанные свежим Lockpick_RCM. `title.keys` — другой файл.

**«personalized ticket» / «no ticket for rights id»** — снимите NSP заново с включённой опцией nxdumptool *remove
console specific data* (и с тикетом).

**«not enough free space»** — освободите место или вынесите рабочую папку на другой диск: `setup.bat --work D:\dos2-work`
(Windows) или `bash setup.sh --work /mnt/big/dos2-work`.

**Уже ставил старую версию (0.1.x)** — после загрузки новой версии запустите setup ещё раз в той же папке: он пропустит всё,
что ещё актуально, и сделает только изменившееся (для 0.2.0 — пакет сенсорного интерфейса и три новых пака шейдеров, несколько
минут). Потом снова скопируйте на телефон `romfs/Data/TouchUI.pak` и всю папку `dm/shaders` (или всю папку
`DivinityOriginalSin2Mobile`: неизменившиеся файлы можно спокойно перезаписать).

**Ставил старый выпуск с `.ipa`** — она больше не нужна (setup её пропускает). После обновления запустите setup ещё раз:
он переделает только пакет сенсорного интерфейса (этап 9); скопируйте `romfs/Data/TouchUI.pak` на телефон заново.

**Где выбрать язык?** — ⚙ → *Настройки игры…* → *Язык игры*; затем перезапустите игру. Языки встроены.

**Чёрный экран или приложение закрывается** — в ⚙ → *Драйвер Vulkan* попробуйте *Системный*, перезапустите приложение.
Затем откройте issue в этом репозитории с моделью телефона, версией Android и описанием и приложите всю папку
`Download/DivinityOriginalSin2Mobile/logs/`: после падения следующий запуск пишет туда `crash.txt` (с логом упавшего
запуска) и сообщает об этом на экране; `boot.log` и `logcat.txt` текущего запуска и `boot.prev.log` / `logcat.prev.txt`
предыдущего пишутся построчно во время игры (поэтому они есть, даже если Android убил игру). Каждый запуск setup
пишется в `work/setup.log`: прикладывайте его при проблемах с setup.

Технические подробности подготовки (что делает каждый шаг, ручной запуск инструментов): [dos2/GAME_FILES.md](dos2/GAME_FILES.md).
